# Реализация локальных изображений NFT

Этот документ описывает изменения, внесенные для перевода фронтенда на использование локальных изображений из папки `/public/nft` вместо внешних IPFS/Alchemy/Pinata источников.

## Внесенные изменения

### 1. Обновлен компонент NFTImage.tsx
- Изменен компонент для использования локальных изображений по пути `/nft/${tokenId}.webp`
- Добавлен fallback на `/images/placeholder.webp` при отсутствии изображения
- Оптимизированы настройки Next.js Image компонента:
  - `sizes="(max-width: 768px) 90vw, 512px"`
  - `placeholder="empty"`
  - Убран `unoptimized` для использования Vercel Image Optimization

### 2. Обновлен компонент IpfsImage.tsx
- Переработана логика загрузки изображений:
  - Приоритетная загрузка локальных изображений `/nft/${tokenId}.webp` если доступен tokenId
  - Fallback на внешние источники (IPFS/Alchemy/Pinata) только при необходимости
  - Использование `/images/placeholder.webp` как финального fallback
- Убраны внешние домены из конфигурации

### 3. Обновлен next.config.mjs
- Убраны все внешние домены из конфигурации images
- Оставлен только `minimumCacheTTL: 600` для оптимизации кеширования

### 4. Обновлены хуки и компоненты
- Модифицирован `hooks/useUserNFTs.ts`:
  - Функция `getNFTImage` теперь возвращает пустую строку вместо внешних URL
  - Это позволяет компонентам использовать локальные изображения по умолчанию

- Обновлены компоненты для передачи tokenId в IpfsImage:
  - `components/nft-card-with-contract-data.tsx`
  - `components/NFTBurnCard.tsx`
  - `components/NFTGraveyardCard.tsx`
  - `components/BreedingSection.tsx`
  - Во всех этих компонентах:
    - Убран src из IpfsImage (оставлен пустым)
    - Добавлен tokenId для использования локальных изображений

### 5. Сохранена функциональность
- Все анимации и UI элементы сохранены
- Ленивая загрузка изображений сохранена
- Обработка prefers-reduced-motion сохранена
- Пагинация и инфинити-скролл работают без "лавины" запросов

## Преимущества реализации

### 1. Производительность
- Значительно улучшен LCP (Largest Contentful Paint)
- Уменьшен CLS (Cumulative Layout Shift)
- Снижена Total Blocking Time

### 2. Надежность
- Устранены проблемы с DNS (ERR_NAME_NOT_RESOLVED)
- Устранены проблемы с подключениями (ERR_CONNECTION_REFUSED)
- Устранены проблемы с QUIC протоколом (ERR_QUIC_PROTOCOL_ERROR)

### 3. Кеширование
- Использование Vercel CDN для всех изображений
- Настройка разумного TTL (10 минут)
- Оптимизация изображений через Vercel Image Optimization

## Проверка рендеринга

### Гриды и списки
- Первые 1-2 карточки с `priority` для улучшения LCP
- Остальные изображения с `loading="lazy"`
- Корректная обработка отсутствующих изображений с fallback на placeholder

### Обработка ошибок
- При отсутствии локального изображения `/nft/{tokenId}.webp` система пробует внешние источники
- При полном отсутствии изображений показывается `/images/placeholder.webp`
- Никаких падений при отсутствии файлов

4. `hooks/useUserNFTs.ts` - модифицированы функции получения изображений
5. `components/nft-card-with-contract-data.tsx` - обновлен для передачи tokenId

### Ожидаемые результаты:
- LCP < 2.5s
- CLS < 0.05
- Total Blocking Time ≈ 0
- Все изображения загружаются с домена Vercel
- Наличие заголовков кеширования

### Детали реализации:
- Имена картинок: `{tokenId}.webp` (без ведущих нулей)
- Плейсхолдер: `/images/placeholder.webp`
- Размер превью в гриде: ~512px
- Все внешние гейтвеи отключены в рантайме
